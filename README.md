# Custom Keyboards by Alan
A small, responsive website for exploring custom keyboard options and getting in touch about a build.

## What’s on the site
- A keyboard preference picker that suggests a starting point based on layout, switch feel, and intended use.
- A contact form, with an option to add the picker’s suggestion to your message.
- A live character counter that recommends shortening messages over 500 characters. It does not enforce a limit.
- A light/dark theme toggle that remembers your choice.
- A small greeting interaction.

## Run locally
No dependencies or build tools are required. Open `index.html` in a browser to view the site.

## Contact form
The form is set up to submit to `script.php`, but the PHP handler is not included. The form will need a backend handler before it can send messages.

## Project files
- `index.html` — page structure and content
- `style.css` — styling and responsive layouts
- `script.js` — theme, picker, greeting, and character-counter interactions
